# رَوَند — نسخهٔ اندروید (Kotlin)

پورت بومی اندروید از سامانهٔ حضور و غیاب رَوَند (نسخهٔ دسکتاپ Rust + Tauri + SQLite).
همان دیتابیس، همان دادهٔ نمونه و همان جریانهای ورود و ثبت حضور، با رابط فارسی/راستچین.

## فناوریها

| بخش | انتخاب |
|---|---|
| زبان | Kotlin 2.0 |
| رابط | Jetpack Compose + Material 3 |
| دیتابیس | SQLite بومی (`SQLiteOpenHelper`) — فایل `ravand.db` در حافظهٔ خصوصی اپ |
| هش رمز | PBKDF2-HMAC-SHA256 (۱۲۰٬۰۰۰ تکرار + نمک ۱۶ بایتی) |
| ورود پرسنل | TOTP مطابق RFC 6238 (HMAC-SHA1، ۶ رقم، ۳۰ ثانیه، پنجرهٔ ±۱) |
| QR | ZXing |
| خروجیreport | CSV با BOM + اشتراکگذاری از طریق FileProvider |

> نکته: نسخهٔ دسکتاپ از Argon2id استفاده میکند. چون Argon2 در SDK اندروید موجود نیست،
> در این نسخه از PBKDF2WithHmacSHA256 استفاده شده است. هیچ رمزی بهصورت متن ساده ذخیره نمیشود.
> دیتابیس اندروید مستقل است و نیازی به انتقال فایل `ravand.db` دسکتاپ نیست (همان دادهها seed میشوند).

## ساخت و اجرا

1. Android Studio (با Android SDK و JDK 17) را باز کن.
2. پوشهٔ `android` را بهعنوان پروژه باز کن.
3. منتظر Sync گرادلس بمان (اولین بار چند دقیقه طول میکشد).
4. دکمهٔ Run ▶ یا از ترمینال:

```bat
gradlew.bat :app:installDebug
```

حداقل SDK: ۲۶ (Android 8.0) · هدف و کامپایل: ۳۵.

اگر فایل `gradle-wrapper.jar` موجود نبود، یکبار دستور `gradle wrapper --gradle-version 8.9`
را اجرا کن تا Android Studio بهطور خودکار آن را بازسازی کند.

## ورود (اولین اجرا)

- **مدیر**: `admin` / `admin` ← بلافاصله از تنظیمات تغییر بده.

> در نسخهٔ موبایل تنها ورود مدیر وجود دارد. ثبت ورود، خروج و مرخصی کارکنان
> توسط همین پنل مدیریت (از کارت هر کارمند) انجام میشود. ورود جداگانهٔ پرسنل و
> کد Google Authenticator در این نسخه حذف شده است.

## قابلیتها

- افزودن، ویرایش، حذف و جستجو/فیلتر کارکنان
- ثبت ورود / خروج / مرخصی توسط مدیر (بدون نیاز به کد)
- حذف ورود پرسنل؛ تمام ثبتها توسط مدیر انجام میشود
- نگهداری قابلیت Authenticator در لایهٔ داده (برای سازگاری با نسخهٔ دسکتاپ)
- تنظیمات: ۵ تم رنگی، ۲ فونت (آراد / وزیرمتن)، نام مجموعه، تغییر نام کاربری و رمز مدیر
- دورههای حقوق: افزودن و مشاهده
- خروجی CSV سازگار با اکسل فارسی (BOM + CRLF)
- پنل جداگانهٔ پرسنل با آمار و آخرین رویدادها

## ساختار

```
android/
├── build.gradle.kts / settings.gradle.kts / gradle.properties
├── app/src/main/
│   ├── AndroidManifest.xml
│   ├── res/font/arad.ttf        ← کپی شده از ui/fonts نسخهٔ دسکتاپ
│   ├── res/xml/file_paths.xml   ← FileProvider برای خروجی CSV
│   └── java/ir/ravand/app/
│       ├── MainActivity.kt
│       ├── data/                ← مدلها، SQLite، Cryptography، Repository
│       ├── ui/                  ← تم، فرمت فارسی، صفحات و مودالها
│       └── viewmodel/           ← UiState و MainViewModel
```

برای اضافه کردن فونت وزیرمتن، فایل `vazirmatn.ttf` را در `res/font/` قرار بده و
در `ui/Theme.kt` عبارت `FontFamily.SansSerif` را با `FontFamily(Font(R.font.vazirmatn))` جایگزین کن.
